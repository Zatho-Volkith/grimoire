# Icons

Drop one SVG per slot here; anything missing shows a lettered placeholder.

- Size: 24×24 viewBox, single colour (it is tinted at runtime to match the text around it).
- File names (one per `IconSlot`): `character.svg`, `location.svg`, `faction.svg`, `item.svg`,
  `concept.svg`, `system.svg`, `works.svg`, `timeline.svg`, `templates.svg`, `trash.svg`,
  `search.svg`, `add.svg`, `close.svg`, `export.svg`, `settings.svg`, `back.svg`.
