# Test fixtures

`teleportation.json` and `v-character.json` are recorded MediaWiki API responses, used to test
wiki import against real-world wikitext:

- `teleportation.json` — ["Teleportation"](https://powerlisting.fandom.com/wiki/Teleportation)
  from the Superpower Wiki (powerlisting.fandom.com)
- `v-character.json` — ["V (character)"](https://cyberpunk.fandom.com/wiki/V_(character))
  from the Cyberpunk Wiki (cyberpunk.fandom.com)

The article text inside them is community-written wiki content, licensed CC BY-SA by the
respective wikis and included here solely as test data, with attribution above.
